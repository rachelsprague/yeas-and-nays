Privacy

Privacy

Yeas & Nays has no accounts, forms or ads, and sets no cookies. It counts visits with a cookieless analytics service, and like any website, the services that host and serve it see each visitor's IP address.

On this page Analytics Opting out Hosting and fonts

Analytics

Visits are counted with Umami Cloud, which does not use cookies. For each page view, Umami records the page address and title, the referring site, browser, operating system, device type, screen size, language and approximate location (country, region and city), which it derives from the IP address.

Umami does not store the IP address in its analytics records. To count repeat visits without cookies, it combines the IP address and browser details with a value that changes every month into an anonymous identifier. Umami and its infrastructure providers may keep IP addresses in operational and security logs. See Umami's privacy policy.

Page views are sent only from yeasandnaysdata.com, and not from a browser with Do Not Track turned on. In both cases the Umami script still loads.

Opting out

Open any page with ?notrack=1 at the end of the address, such as yeasandnaysdata.com/?notrack=1. From then on, this browser sends no page views to Umami from this site, on later visits too. The Umami script still loads, but sends nothing.

The setting is saved in this browser only, in its local storage for this site. It lasts until you open a page with ?notrack=0 at the end of the address or clear this site's data. Other browsers and devices need their own opt-out.

Anyone who opens a link ending in ?notrack=1 is opted out the same way, so remove it from a link before sharing it.

Hosting and fonts

The site is hosted on GitHub Pages. GitHub logs and stores each visitor's IP address for security purposes. See GitHub's privacy statement.

The site's fonts load from Google Fonts, so a browser requests them from Google's servers, which receive the visitor's IP address with each request. See Google's privacy policy.
